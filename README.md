# LMSNRM QGIS-updates

Publieke installatiebestanden, zonder Zones, INWEVA, projectenlijst of modelnetwerken.

Download de ZIP in `packages` en installeer via QGIS > Plugins > Installeren vanuit ZIP. Updates werken zonder login; nieuwe versies worden bij de volgende QGIS-start geïnstalleerd.

De interne gegevens worden afzonderlijk beheerd op de netwerkschijf.

Voor publicatie van een volgende versie: vervang/voeg de twee plugin-ZIP’s in packages toe. De workflow vernieuwt de versielijst en publiceert een release automatisch.
